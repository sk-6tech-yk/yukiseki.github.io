自己紹介

はじめまして。関佑貴と申します。

2011年より専修大学ネットワーク情報学部にて、プログラミングやAdobeソフトを用いた制作、データベース構築などの基礎を習得するとともに、チームでのWebシステム開発を通じて実践的な開発プロセスを学びました。

2015年から2026年まで株式会社ネイティブキャンプ制作部にて、フロントエンドエンジニア／ブリッジエンジニアとして従事。英語を用いたコミュニケーションにより、海外エンジニアとの連携にも対応しています。HTML / CSS / JavaScript / PHPを用いた開発を中心に、WordPressやShopifyの構築・カスタマイズまで幅広く手がけています。

デザインの再現性に加え、ユーザビリティや保守性を考慮した実装を得意とし、長期的な運用を見据えた設計に強みがあります。チーム開発では、Gitを用いたバージョン管理やDocker / Vagrantによる開発環境構築にも対応しています。
